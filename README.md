# VJAlgo Trading Dashboard

A live trading dashboard for StockScanner. Hosted on GitHub Pages.
Data is published from your trading machine automatically.

---

## Architecture

```
Your Machine (Windows)
  └── publish_data.py
       ├── reads: real_trades.db, scanner.db
       ├── reads: picks.csv, post_exit_tracker.csv, priority_watchlist.csv
       └── writes JSON → docs/data/ → git push → GitHub Pages

GitHub Pages (www.vjalgo.online)
  └── index.html reads docs/data/*.json → Live Dashboard
```

---

## One-Time Setup

### Step 1 — Create GitHub Repository

1. Go to https://github.com/new
2. Repository name: `vjalgodash`
3. Set to **Public** (required for free GitHub Pages)
4. Click **Create repository**

### Step 2 — Upload these files

Upload the entire contents of this ZIP to your repository:
- Drag and drop all files in GitHub's web interface, **or**
- Clone and push (preferred):

```
git clone https://github.com/YOUR_USERNAME/vjalgodash.git
# copy all these files into that folder
cd vjalgodash
git add .
git commit -m "initial setup"
git push
```

### Step 3 — Enable GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` → Folder: `/docs`
4. Click **Save**
5. Wait 2 minutes → your site will be at:
   `https://YOUR_USERNAME.github.io/vjalgodash`

### Step 4 — Custom Domain (if you have vjalgo.online)

1. In Pages settings → Custom domain → enter `www.vjalgo.online`
2. In your DNS provider (Cloudflare), add:
   - CNAME `www` → `YOUR_USERNAME.github.io`
3. Enable **Enforce HTTPS**

### Step 5 — Install Python dependency

On your trading machine (Windows):
```
pip install gitpython
```

### Step 6 — Configure publish_data.py

Open `scripts/publish_data.py` and edit the CONFIG section:

```python
CONFIG = {
    "real_trades_db":  r"D:\SO\data\real_trades.db",   # ← your actual path
    "scanner_db":      r"D:\SO\data\scanner.db",        # ← your actual path
    "picks_csv":       r"D:\SO\data\picks.csv",
    "post_exit_csv":   r"D:\SO\data\post_exit_tracker.csv",
    "priority_csv":    r"D:\SO\data\priority_watchlist.csv",
    "repo_path":       r"D:\vjalgodash",               # ← where you cloned the repo
    "auto_push":       True,
}
```

### Step 7 — Run the publisher

**Single run:**
```
python scripts\publish_data.py
```

**Continuous (every 5 minutes):**
```
python scripts\publish_data.py --watch
```

**Custom interval (every 60 seconds):**
```
python scripts\publish_data.py --watch --interval 60
```

## Dashboard Pages

| Page | What it shows |
|------|--------------|
| ⚡ Live Trading | Open positions, daily P&L history, all-time stats |
| 📒 Trade Journal | All real trades with filters by strategy/direction/result |
| 🎯 Signals | Stock picks from scanner — PENDING/ACTIVE/EXPIRED |
| 👁 Watchlist | Priority watchlist ranked by composite score |
| 📊 Analytics | Strategy breakdown, paper vs real, cumulative P&L chart |
| 🔍 Post-Exit | Was our exit correct? What happened after we sold? |

## Automation (Optional — Run publish_data.py automatically)

### Windows Task Scheduler

1. Open **Task Scheduler** → Create Basic Task
2. Name: `VJAlgo Publisher`
3. Trigger: **Daily** → repeat every 5 minutes
4. Action: Start a program
   - Program: `python`
   - Arguments: `scripts\publish_data.py`
   - Start in: `D:\vjalgodash`
5. Finish

This way you don't need to manually run the script — it publishes on its own during market hours.
